# Plinko

Plinko game built with React, TypeScript, Vite and Phaser 3 (Matter physics).

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – type-check and build for production
- `npm run lint` – run ESLint
- `npm run preview` – preview the production build

## Structure

- `src/components/games/plinko` – Phaser game config and scenes (`loadingScene`, `gameScene`)
- `src/components/ui` – React UI layout, controls, modals and messages
- `src/store` – Zustand stores
- `public/plinkoGameAssets` – game images, video and audio
